阅读提要

内核管理资源与执行，用户态组织服务与程序运行，产品层提供安装、更新和恢复。

正文包括系统边界、L0–L7 概念层次、启动、架构、中断、并发、任务、内存、接口、IPC、驱动、存储、文件系统、网络、安全、虚拟化、电源、服务、界面、维护和验证体系。

“完整”由目标用途和可验证的系统契约定义。服务器无需桌面，嵌入式系统也不必实现通用桌面 OS 的全部能力。
